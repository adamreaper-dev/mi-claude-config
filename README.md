# mi-claude-config

Personal configuration files for [Claude Code](https://claude.ai/code).

## Contents

- `.claude/` — Claude Code settings and permissions
- `backups/` — Automatic backups of configuration
- `memory/` — Persistent memory files used by Claude across sessions
- `projects/` — Per-project conversation history
- `sessions/` — Session data
- `shell-snapshots/` — Shell environment snapshots
